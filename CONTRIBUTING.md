# Contributing

Codex Mobile is currently a single-owner project and is not accepting external
code contributions. Public visibility is for review and transparency; apart
from the limited rights GitHub's Terms provide for platform features, it does
not grant a license to copy, modify, or redistribute the project.

Security reports should follow [SECURITY.md](SECURITY.md). For ordinary
questions, use the support route in [SUPPORT.md](SUPPORT.md). Please do not open
a pull request unless the owner has invited that specific contribution.
